## 前言

![Oranges](/static/images/science/Oranges.png)

_地球是你永远展不平的橘子皮。_
_——鹅仔_

前一段时间逛知乎，看到一个问题：现实世界中是否存在非欧几何空间？。又联想到之前有个很蠢的阴谋论是关于地球是平的之类的。不由得感慨，地球上对地球有基本认识的人似乎很少。那么今天就来说说，我们脚下的地球和早就想聊的CRS，也就是Coordination reference system（坐标参照系统）。

很多人喜欢说坐标参照系统分两种，**地理**和**投影**。然而这样的分类让人很迷惑，我自己也经常搞晕。如果方便点区分，前者的单位是度——也就是经度纬度的那个度，即所有的数据其实是建立在一个椭球形的曲面坐标上的。而后者，单位是距离（以米为主，也有一些国家使用英尺，在此不点名）则把度以不同的方式转换为实际的距离，使所有的坐标能够出现在一个平面上，使之成为能够指导生产生活的地图。与其说这两个概念是并列的概念，倒不如说是存在一定的递进关系。


## 地理坐标参照系统：从三角测量到GPS

地理坐标参照系统其实我们大家都很熟悉了，也就是以经线和纬线为x和y。纬线平行于赤道，而经线垂直于纬线。然而，虽然经度和纬度的概念早已有之，但是真正细化经度和纬度，以达到一个全球统一的高精度标准，则跨越了几百多年。

或许有很多人有疑问，航海的时候不是有地图吗，地图上不是有经线和纬线吗。诚然，各个国家都通过测绘建立了自己国家的、乃至世界的地图，但是这种非常原始的制图方法中的经度纬度固然能够帮助我们了解国家和城市的大概方位，但是其准确程度和精度简直不堪一击。

![6709A-map-web](/static/images/science/6709A-map-web.jpg)
- 17世纪 荷兰黄金时代绘制的 世界地图 

要知道，对于一个航海的水手来说，如果不能搞清楚所在地理位置的真实经度方位，轻则耽误航程，重则船毁人亡。因而，英国议会于1714 年颁布“经度法案”（Longitude Act）开始鼓励发明精确测定经度的仪器或方法。在此后，陆续开始有很多钟表匠挑战英国政府当时重金扶持的科研项目。1759年，在经历了数十年的升级改造之后，约翰·哈里森（John Harrison）发明的H4让经度测定精确到 1°甚至更小，极大提高航海安全。也为大家更深入了解地球这个坐标系统迈出了坚实的一步。

测量的问题暂时解决了，但是经度从哪里开始计算，各个国家之间怎么取得一个统一的坐标系统又是另一件事。自然，每个国家都倾向于把自己的国家放在0度的位置，就好像每个人思考方位的时候也会总想着以自己家为参考原点。于是，法国人把原点选在巴黎，英国人把原点选在伦敦，然而，这对于商贸往来以及航行当然造成了很大的困惑甚至是偏差。于是在1884年，22 个国家参加了在华盛顿召开了国际子午线会议（Washington, D.C. ），投票确定了格林尼治天文台经线定为经度 0°。至此，现代经纬度、全球制图和时区制度的基础被奠定了。

在此后出现的地图上，我们也已经看到了现代世界地图的雏形以及数字标注的经线纬线：

![5117311_wmark](/static/images/science/5117311_wmark.jpeg)
- 19世纪 美国出版商 Rand McNally 出版的 世界地图

另一方面，大地测量学的进展又使得人们对地球的形状有了更深刻的感知。19世纪初，随着测量精度的提高，拉普拉斯和高斯通过对各地弧度测量结果的研究，相继指出地球的非椭球性。的确，地球并非一个完美的球体，甚至不是一个完美的椭球。这个球的具体形状则影响到了经度如何在地球上铺展开来。早期的椭球模型以局部的天文和三角测量数据为基础，在局部拟合优异，比如Clarke 1866（被美国用作其NAD27基础），Airy 1830（被英国作为其OSGB36的基础）。然而，这些椭球在全球的通用性并不高。

1873年，大地水准面的概念被提了出来：地表是非常复杂且在不断变化的，这就需要我们确立地球的物理和数学形状——通常是将重力场中整体形状与地形表面最为接近的的重力等位面作为地球的形状进行研究。有了这样的假设，大地测量学家们开始通过现有的三角测量数据结合重力数据修正来建模拟合椭球。而1910年，美国测量学家Hayford建立的椭球模型于1924被 IUGG（国际大地测量与地球物理联合会）采纳，成为了第一个全球通用的椭球模型（International Ellipsoid 1924）。二战后，欧洲建立的ED50也正是建立在这个版本的椭球之上。然而，其局部精度略逊色于国家系统。

建模的手段已经有了，数据问题终究是老大难。在地球上，人能对地球的测量终究是有限的，这些前 GPS 时代的地理坐标系统，本质上都是建立在有限地面测量与天文观测基础上的区域最优解。但倘若有什么设备能够跳出地球，让地球上的一切不就一览无余，岂不美哉。于是，上个世纪五十年代美军便开始着手研制卫星定位系统。一方面，是由探索宇宙以及建立国际空间站的发展所推动，另一方面，也是由于冷战的背景下，北约希望确立一个北约范围内的地理空间参考系统用于导航、航空、运输以及军事活动。

1960年，美国国防部推出了1960年世界大地测量系统（WGS 60）。在这个测量系统中，不仅包含了经度纬度，也将地球的海拔和重力场（确定地表每个点的法向）考虑进来，成功将不同地区的数据拼凑在一起，并将高程重新参考到一个椭圆体模型之上。就这样，一个全球统一的坐标参考系统就这么被建立了起来。在此之后的数十年间，随着全球卫星观测站的建立，这个系统又不断被更新优化，有了WGS 66， WGS 72等好几代新的系统。

### WGS84

1984年，在遍布世界的卫星观测站帮助下，WGS84被确立。这个新的框架确立了地心为原点，定义精确了椭球参数（见下表）和地球固定坐标系。

| 参数      | 数值              | 说明                 |
| ------- | --------------- | ------------------ |
| 长半轴 (a) | 6378137.0 m     | 地球椭球的赤道半径          |
| 扁率 (f)  | 1/298.257223563 | 地球扁平化程度（赤道半径与极半径差） |
| 极半径 (b) | 6356752.3142 m  | 根据 (b = a(1-f)) 计算 |
![WGS_84_reference](/static/images/science/WGS_84_reference.png)
  - WGS84 所定义的地球参数 

直到今天，WGS84依旧是我们所广泛使用的国际通用的的地理坐标系统。（尽管自 1984 年建立以来，它已经经过多次更新和微调，以适应卫星测量精度提升和地球物理变化。）我们的谷歌地图，以及很多地图网站所使用的经纬数据也都是基于这个框架。

## 投影坐标参照系统

然而，经纬度的问题解决了。另一个问题又出现了：假如我们需要制作地图，如何精准地在一张二维的图纸上展现和表达这些数据呢？正方体可以展开，圆柱体可以展开，圆锥可以展开，但是球体，怎么展开呢？答案就是，完全不失真的地图根本不存在。

是的，没错，当我们用尽一切方法将“度”转换成“米"，误差总是存在——地球表面不属于欧几里得数学管辖的范畴了。于是，关于如何尽可能不那么失真地将这个球体上的所有信息表达在平面上就成了投影坐标参照系统要解决的问题。

千奇百怪的脑洞当然就出现了：

#### 和非洲一样大的格陵兰？—— 基于圆柱体的投影

首先，最简单的想法当然是：就经纬度画成横平竖直的呗，既然他们在空间上本身就是垂直的。这正是我们之前上一节内容中看到的历史地图的绘制方法——墨卡托投影法 (Mercator projection)。其要义非常简单直观，就是直接把经纬改换成垂直的x和y轴——相当于把球体上的信息投影到了一个圆柱体上。然而，这样的投影对于高纬度地区高度失真，最经典的莫过于格林兰岛和非洲的面积看上去已经差不多了。要知道，格林兰岛只有区区两百多万平方公里，而非洲大陆的面积大约为3020万平方公里，相当于三倍于中国的面积。因而，我们大部分习惯了这张地图的人，世界面积观可以说是相当完全虚构的（？。
![Mercator_projection_Square](/static/images/science/Mercator_projection_Square.jpg)
- 世界地图 World Map - Mercator Projection 

当然，也有后来者试图解决这个问题，尝试把高纬度地区的y轴缩放一下。这就是miller cylindrical投影。治标不治本，我们企鹅统治的南极还是横跨整个地球的超级第一大洲呢！

#### 南极探险 导弹和 航空？—— 基于方位角的投影


圆柱投影的另一个问题在于对于两点之间的方位和距离计算的错误。我们再举南极洲的极端例子，倘若在南极洲内探险，有不同的AB两点，如何判断从A到B要走多远、什么方位，上图似乎也并不能给出一个直观的答案。

不过，对于这个问题，南极探险队倒是早有答案：
我们所熟知的南极地图正是将所有信息投影到了一个以南极点为中心的圆形上。否则我们知道，这张地图的上下左右理论来说都是往北…

#### 给地球寻找甜筒皮… 基于圆锥的投影

当然，极坐标投影有趣是有趣，但这些距离终究是基于一个圆心的，其使用的场景实在是太过局限。（我们总不能每到一个地方就重新投影吧。-怎么不行呢）。

那么，既然圆柱和圆都不行，怎么不把二者结合起来…试试圆锥呢？

尝试想象一下下图这样的过程，我们会发现在国家层面上，特别是中纬度、跨经线方向较长的国家，很容易找到一个适合自己的圆锥曲面来大致代替球体，而且保证平行于选定的标准纬线方向的距离不失真。

#### 折中一下吧——Robinson和Mollweide 

看来，使用其他规则曲面投影后都让地球变得”虽然准确“，"但是陌生"了…，那么要不就寻找一个别的平面形状呢？

![Earth_reversed](/static/images/science/Earth_reversed.gif)
- 从Mercator 到Robinson 再到 Mollweide - 作者自制

我们在世界统计中上经常见到的，两边是弧线的胖胖的地图，其实就是基于这个想法。这样的投影就将高纬度的纬线们依次进行了不同比例的收缩，使之对于面积和形状的失真尽量变小：

例如下图的Robinson投影就是基于Mercator投影对纬度进行了距离转换，使之更接近球体上真实纬线的长度：

![Robinson_projection_SW](/static/images/science/Robinson_projection_SW.jpg)
-  世界地图 Robinson projection

当然，还有更极端的将南北极收缩成真正的点的Mollweide投影。

![Mollweide_projection_SW](/static/images/science/Mollweide_projection_SW.jpg)
-  世界地图 Mollweide projection

而且，由于Mollweide的纬线间距相对于真实的球弧被压缩，而纬线的总长度（即经线间的距离）则被刻意拉长，最终保证了投影结果和真正的地表面积一直。这使得Mollweide这个版本的地图在生态学、气候学、环境学等关注面积的学科被广泛应用。

然而，面积上虽然Mollweide更准确，但是不得不说，形状却有些失真，因而，在日常生活中还是Robinson这样既保全了形状又让距离得以接近真实情况的版本得以广泛使用了。

#### 将球拆成橘子皮：从Goode homolosine 到UTM

当然，既然是球面，为什么总想着投影到一个完整的形状上呢？为什么不投影变换到到多个形状上再展开呢。

于是，就有了下图中将地球像纸糊的灯笼一样拼起来的世界地图：
![Goode_homolosine](/static/images/science/Goode_homolosine_projection_SW.jpg)

- 世界地图 Goode Homolosine projection 

不难发现高纬度和低纬度地区之间有个明确的转折点，这正是因为它是将两个不同的等面积投影拼接而成（其中一个正是我们上面说的Mollweide哦）。在尽量保全大陆形状不失真的前提下，又将原有的形状进行了不一样的”展开“。这尽量地留存了形状（虽然还是有点变形）并且也保留了面积不失真。

当然，这样将地球近似展开的想法也被沿用在了目前世界最通用的UTM坐标参照系统之中：
![UTM](/static/images/science/UTM.png)
- UTM 世界分区 

UTM系统将世界每6度分了一个区，也就是60个区（见上图），这每个区对应着下图这样一个细长的”球皮面“
![UTMzone](/static/images/science/UTMzone.png)

这样在不同纬度上，6度所跨越的长度逐渐从赤道向两级递减。根据这个，我们便可以进行从地理经纬坐标到长度坐标的转换。我们平常使用的不同国家地区的GIS数据，如果是采用UTM的坐标系统，通常会给一个类似于UTM-30N这样的代码，这正是其数据库所使用的”球皮编号“啦。有了这个编号，我们就可以找到将坐标的x y和经纬度之间转换的方法。尽管拟合的误差依旧存在，但是在6度的区间已经允许该系统在城市以及区域工程的尺度上被广泛使用。

#### 小结

总而言之，世界上没有完美的地图，亦没有完全正确的地图，有的只是适合某一个场景、用途的地图。或许有人会在家里挂一张Goode Homolosine，图个艺术效果和陌生感。但更多的人会选择Robinson这样看着形状中规中矩没有离谱变形虽然面积距离全都不太正确的地图。又或者你要去南极，选择极坐标地图就好了。最终我们只是要选择一个在某个情境、或是某个尺度下能够为你的工作带来便利的投影方法。

## 说回地球

好了，这一期的内容干货很多呀。但是梳理清楚了各个坐标参照系统生成的逻辑之后觉得这个知识点也没有那么琐碎。总之就是每个国家、每个人都在想办法提出自己的建模成果吧。他们其中有的是基于如何把地球上的每一个点抽象到一个椭球上的，有的又是关于如何把地球上的点表达到平面上的。总之，希望任何之前像我一样看了CRS就晕头转向的人能够受用。
